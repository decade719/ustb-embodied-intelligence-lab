## 🚀 快速开始

### 本地运行

```bash
# 方法1: 使用Python
cd 实验室网页
python -m http.server 8080
# 访问 http://localhost:8080

# 方法2: 使用批处理文件（Windows）
双击 start_server.bat
```

## 📦 部署

### 免费部署方案

1. **Vercel部署**（推荐）
   - 访问 https://vercel.com
   - 连接GitHub仓库
   - 自动部署

2. **Netlify部署**
   - 访问 https://netlify.com
   - 拖拽文件夹或连接GitHub

3. **GitHub Pages**
   - 推送到GitHub仓库
   - 在Settings中启用Pages

详细部署指南请查看：[免费部署指南.md](./免费部署指南.md)
